# 文献 AI 筛选与智能推送工作流

> 从自己的论文选题需求出发，把知网 / WOS 导出的分散文献，自动整理成一封带相关度、判定理由和原文入口的阅读简报。

[在线查看](https://curious-leila.github.io/literature-tracker/) · [运行证据](https://curious-leila.github.io/literature-tracker/run-summary.json) · [Prompt 迭代记录](docs/prompt-tuning-log.md)

## 30 秒了解项目

准备毕业论文选题时，我需要持续关注“翻译学 × 文化记忆”这一小众交叉领域。相关文献散落在知网和 WOS，不同关键词还会返回重复结果；每周都要重新合并文件、排除重复项，再逐篇判断是否真正相关，需求阶段估算约耗时 2 小时。

因此，我为自己设计了一套轻量工作流：把平台导出的检索文件放进项目目录，系统自动完成格式解析、历史去重、LLM 三级筛选、简报整理和邮件推送。收到邮件后，可以直接按照“优先阅读全文 / 浏览摘要 / 背景参考”开始阅读，而不是再次面对一份未经整理的搜索结果。

这不是一个假设出来的通用 AI 平台，而是针对真实、重复发生的信息筛选任务做的个人效率工具。

## 问题定义

原来的人工流程有三个主要问题：

- **来源分散**：知网与 WOS 使用不同的导出格式，需要手工合并；
- **重复劳动**：跨关键词、跨周检索会反复出现同一篇文献；
- **关键词不等于相关**：标题里同时出现“翻译”和“记忆”，也不代表论文真的研究二者关系。

因此，项目目标被收敛为：

> 用户完成必要的平台检索和文件导出后，系统自动交付一份去重、分级、说明理由且可直达原文的阅读清单。

## 产品方案

### 工作流

```mermaid
flowchart LR
    A["知网 / WOS 检索导出"] --> B["双格式解析"]
    B --> C["SQLite 历史去重"]
    C --> D["Qwen 三级筛选"]
    D --> E["生成结构化简报"]
    E --> F["邮件推送"]
```

源站检索与导出仍由人完成，因为学校权限和检索策略需要用户控制；自动化从文件导入开始。

### 核心体验

1. **低门槛输入**：将知网 RefWorks 或 WOS RIS 文件放入 `data/imports/`；
2. **避免重复阅读**：SQLite 保存历史文献与推送状态，跨文件、跨批次去重；
3. **给出阅读动作**：LLM 输出 HIGH / MEDIUM / LOW，同时说明判定理由、研究交叉点和阅读建议；
4. **结果直接送达**：简报按相关度与期刊等级排序，通过邮件推送并保留原文入口。

## 关键产品决策

| 产品问题 | 我的判断 | 解决方案 |
|---|---|---|
| 平台存在学校权限限制 | 自动抓取会显著增加复杂度，也不是当前核心问题 | 保留人工检索导出，将自动化边界放在文件导入之后 |
| 关键词筛选误判较多 | 需要判断研究对象与理论框架，而不只是词语命中 | 用 LLM 进行三级语义判断，并要求返回具体理由 |
| 用户最终需要决定先读什么 | 分类标签必须对应下一步行动 | 将三级结果映射为阅读全文、浏览摘要、背景参考 |
| 每周运行可能重复推送 | 去重不应只发生在单个文件内部 | 使用 SQLite 保存历史唯一键与 pushed 状态 |
| 外部模型和邮件都可能失败 | 自动化不能因一次失败产生错误状态 | 分析不完整则拒绝整批写入；邮件失败则保留待推送状态 |

## Prompt 如何迭代

项目共记录 8 轮 Prompt 与模型调整，其中四个关键节点是：

| 版本 | 问题与调整 | 可确认结果 |
|---|---|---|
| v1 | 使用 JSON 输出 | Qwen 7B 的批量结果无法稳定解析 |
| v2 | 改为管道分隔行，并加入完整示例 | 159 / 159 条结果成功解析 |
| v3 | 增加硬性条件和负面排除规则 | 修正“标题命中关键词但研究角度无关”的误判 |
| v8 | 切换 Qwen2.5-32B，并要求具体判定理由 | 形成当前真实运行记录 |

这里的 **159 / 159 指结构化结果能够被程序解析**，不是分类准确率。当前没有人工金标集，因此不使用未经验证的“85% 准确率”作为项目结论。

## 当前边界

- 每周约 2 小时是需求阶段自述基线，未保留受控计时实验，因此不声称“提效 24 倍”；
- 当前没有独立人工金标评测，不声称具体分类准确率；
- 数据源、判断规则和输出层具备迁移思路，但竞品情报、用户反馈等场景尚未实测。
