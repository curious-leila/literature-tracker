# Evidence dashboard technical specification

## Delivery

- Source lives in `web/`; `docs/` remains documentation-only.
- Vite emits a static `web/dist/` bundle with the `/literature-tracker/` base path.
- GitHub Pages deploys the bundle through a dedicated Actions workflow.

## Stack

- React + TypeScript: explicit data contracts and maintainable evidence components.
- Radix UI: keyboard-accessible tabs and tooltips without a preset visual theme.
- Recharts: responsive, labelled distribution chart driven by recorded-run data.
- Lucide React: one consistent SVG icon family; no emoji UI icons.
- CSS design tokens: project-specific visual identity without a generic component-library skin.

## Evidence contract

- `public/run-summary.json` is generated by `scripts/build_evidence.py`.
- The page never invents counts; cards, charts, cases, and the record explorer consume the same artifact.
- Recorded-run facts, evaluated metrics, and unvalidated transfer ideas are visually distinct.

## UX rules

- The first viewport exposes the verified pipeline and headline counts.
- Every interactive target is keyboard accessible and at least 44px high on touch layouts.
- Motion is limited to short opacity/translation transitions and disabled under `prefers-reduced-motion`.
- Breakpoints are verified at 375, 768, 1024, and 1440px without horizontal overflow.
